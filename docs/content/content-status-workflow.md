# Content Status Workflow

## Goal
Move content through a clear pipeline so it does not get lost.

## Statuses
### 1. Idea
Early concept or rough hook only.

### 2. Draft Ready
Hook and caption direction exist, but the final asset is not fully packaged.

### 3. Ready to Film
Script / shot direction is ready and the only missing step is content capture.

### 4. Ready to Post
Caption, concept, and asset are ready or almost ready. Minimal work left.

### 5. Posted
Content is live and should move into the archive.

## Rule
If a post is strong enough to publish, move it into the Ready to Post board so it stays visible.
