# GitHub Pages Notes

This folder contains a static GitHub Pages-friendly dashboard for NCS Aesthetics.

## Suggested deployment options
### Option 1: Root deployment via `/site`
In GitHub repo settings:
- Pages -> Build and deployment
- Source: Deploy from a branch
- Branch: `main`
- Folder: `/site`

### Option 2: Copy to root later
If preferred, the site can be moved to the repo root later, but `/site` is cleaner for now.

## Main file
- `index.html`
- `styles.css`

## Design intent
The aesthetic is soft, feminine, polished, neutral, and luxury-leaning to echo NCS Aesthetics' public brand and GlossGenius feel.
