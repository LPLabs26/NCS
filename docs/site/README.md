# GitHub Pages Notes

This folder contains the site assets mirrored into the repo's static deployment surfaces.

## Suggested deployment options
### Recommended GitHub Pages deployment
In GitHub repo settings:
- Pages -> Build and deployment
- Source: Deploy from a branch
- Branch: `main`
- Folder: `/docs`

## Notes
- `site/` is the source-facing front door inside the repo.
- `docs/` is the GitHub Pages-friendly mirrored surface.
- `mission-control/` and `docs/mission-control/` should stay in sync.

## Main file
- `index.html`
- `styles.css`

## Design intent
The aesthetic is soft, feminine, polished, neutral, and luxury-leaning to echo NCS Aesthetics' public brand and GlossGenius feel.
