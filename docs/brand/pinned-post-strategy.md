# Pinned Post Strategy

## Goal
Use pinned posts to answer the top three booking questions immediately.

## Pin 1 - Welcome to NCS
Should explain:
- who Natalie is
- what NCS specializes in
- what kind of experience clients can expect

## Pin 2 - Hydrafacial
Should explain:
- what it is
- why it’s the hero service
- who it’s best for
- visible result angle

## Pin 3 - What should I book?
Should explain:
- if you want glow -> Hydrafacial
- if you’re unsure -> Custom Facial
- if you want correction -> ask about peels

## Result
A new visitor should be able to understand the brand and next step without scrolling too far.
