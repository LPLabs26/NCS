## Primary Posting Workflow
1. Open the NCS approval wall
2. Review the approved post
3. Click into the dedicated post viewer
4. Confirm:
   - title is correct
   - short description is correct
   - caption is correct
   - CTA is correct
5. Copy the final caption
6. Open Instagram account `ncs.aesthetics`
7. Upload the matching post asset
8. Paste the caption
9. Publish the post
10. Confirm it is live
