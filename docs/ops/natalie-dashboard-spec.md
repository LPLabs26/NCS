# Natalie Dashboard Spec

## Purpose
A lightweight weekly dashboard for tracking content, inquiries, and booking momentum.

## Core sections

### 1. Bookings
Track:
- total bookings this week
- Hydrafacial bookings
- Custom Facial bookings
- Peel bookings
- open slots / weak days

### 2. Content
Track:
- reels posted
- stories posted
- carousels posted
- best-performing post
- saves / shares / replies if available

### 3. DMs / Leads
Track:
- treatment questions
- booking questions
- pricing objections
- first-time client interest
- follow-up opportunities

### 4. Promotions
Track:
- gap-fill posts used
- openings filled after promotion
- strongest urgency angle

### 5. Notes
Track:
- recurring client pain points
- top-performing hooks
- new service ideas / campaign ideas

## Best format
Recommended implementation:
- one Google Sheet tab per month
- one summary page
- one weekly notes area
