# Natalie Admin SOP

## Goal
Create a repeatable weekly admin routine for NCS Aesthetics covering bookings, DMs, content, and follow-up.

## Daily admin tasks
### Morning
- check bookings for the day
- note any open appointment windows
- review DMs and unanswered inquiries
- review today’s content / story plan

### Midday
- check for cancellations or new openings
- post story reminders if needed
- respond to warm leads

### End of day
- note bookings completed
- note new leads or DMs
- identify follow-ups needed
- check whether next-day content is ready

---

## Weekly admin tasks
### Monday
- review week’s schedule
- choose hero offer of the week
- review content calendar
- identify soft booking days

### Wednesday
- check lead status
- send follow-ups where needed
- push gap-fill content if necessary

### Friday
- review wins and bottlenecks
- log top-performing content angles
- note rebooking opportunities
- prep next week’s priorities

---

## Booking admin priorities
1. keep schedule visibility clear
2. identify gaps early
3. push urgency before a day becomes too soft
4. encourage rebooking when clients are satisfied

## DM admin priorities
1. answer quickly
2. reduce booking confusion
3. recommend the next right service
4. follow up when interest is warm

## Content admin priorities
1. keep content aligned to hero offers
2. maintain daily story presence
3. repeat proven hooks
4. track what drives responses and bookings
