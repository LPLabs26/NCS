# Decision Rules

## If an offer gets attention, repeat it
If a service or hook consistently drives engagement or inquiries, use it again in a new format.

## If a post looks nice but drives nothing, do not overvalue it
A beautiful post that creates no inquiries, saves, bookings, or momentum should not be treated as a win.

## If clients are confused, simplify
Whenever there is repeated hesitation around what to book, move people toward one obvious next step.

## If urgency works, use it carefully
Urgency should feel exclusive and elegant, not cheap or panicked.

## If something works twice, systemize it
Turn strong hooks, captions, or DM replies into templates.

## If data is thin, use judgment but keep logging
Early-stage businesses may not have perfect data. Track what you can and refine over time.
