# KPI Interpretation Guide

## Goal
Help interpret NCS dashboard numbers so the team knows what action to take.

## If bookings are low but DMs are high
Interpretation:
- interest exists, conversion is weak

Action:
- improve booking guidance
- use stronger service recommendation scripts
- reduce confusion around what to book

## If reels are getting attention but no inquiries
Interpretation:
- content may be interesting but not conversion-focused

Action:
- strengthen CTA
- tie content more directly to services
- add more educational and trust-building language

## If Hydrafacial gets most attention
Interpretation:
- this is the strongest hero offer

Action:
- feature it more often
- use it as the top entry into maintenance and package sales

## If Custom Facial gets more questions than bookings
Interpretation:
- people like the concept but still need reassurance

Action:
- explain it more clearly as the best option for unsure first-time clients
- use more before/after and trust-based content

## If peels get little attention
Interpretation:
- peel messaging may feel too advanced, intimidating, or underexplained

Action:
- create educational content
- explain benefits in simple language
- use corrective-care authority without sounding harsh

## If openings stay unfilled
Interpretation:
- urgency content is too weak or too late

Action:
- post earlier
- use one clear offer only
- make the opening feel exclusive, not desperate

## If clients are not rebooking
Interpretation:
- consistency story is not landing strongly enough

Action:
- recommend treatment rhythm clearly
- introduce maintenance language more often
- ask for the next booking while satisfaction is high
