# Weekly Reporting System

## Goal
Create a simple way to review NCS performance each week and decide what to repeat, improve, or stop.

## What to review weekly
- bookings
- open appointment windows
- content posted
- lead / DM volume
- strongest offer
- strongest content hook
- rebooking opportunities

## Weekly reporting categories
### 1. Booking Performance
Track:
- total bookings
- Hydrafacial bookings
- Custom Facial bookings
- Peel bookings
- open slots left unfilled

### 2. Content Performance
Track:
- reels posted
- stories posted
- carousels posted
- posts that generated replies, saves, or obvious engagement
- which hook / topic created the most interest

### 3. Lead Performance
Track:
- new inquiries
- booked leads
- unbooked leads
- common questions
- common objections

### 4. Retention Performance
Track:
- clients who rebooked
- clients who said they wanted to rebook
- package interest
- follow-ups still needed

## Weekly questions
1. What content made people act?
2. Which offer got the most interest?
3. Where did leads get stuck?
4. Which service should be pushed harder next week?
5. Which messages felt premium and effective?

## Weekly output format
- biggest win
- biggest bottleneck
- top-performing content angle
- service to promote next
- follow-ups needed
- one thing to repeat next week
- one thing to improve next week
