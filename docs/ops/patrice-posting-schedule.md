## Patrice Workflow
### 1) Morning check
Before posting, Patrice should:
- open the approval wall
- confirm the post is approved
- open the dedicated post viewer
- verify the title, short description, and caption all read cleanly
- verify the CTA matches the post type

### 2) Daily order of posting
Patrice should post in this order:
1. Morning Daily Tip
2. Midday Hydrafacial
3. Evening Circadia

### 3) What each post should feel like
#### Morning — Daily Tips
Goal:
- simple
- useful
- save-worthy
- confidence-building

Do:
- one clear takeaway
- short practical advice
- easy skincare habits

Do not:
- oversell
- sound clinical
- sound like generic motivational content

#### Midday — Hydrafacial
Goal:
- educate
- clarify menu options
- support booking

Do:
- explain service ladder clearly
- mention when Hydrafacial fits
- use specific treatment logic

Do not:
- repeat vague "glow" language
- make every post sound the same
- upsell randomly

#### Evening — Circadia
Goal:
- premium hero content
- barrier support
- routine guidance
- homecare trust

Do:
- keep tone calm and expert-led
- connect the post to real nighttime skin needs
- make the routine feel intentional

Do not:
- get too abstract
- sound like luxury word salad
- feel product-pushy
