# Onboarding Guide

## Purpose
This guide explains how to use the NCS repo as an operating system for brand, content, bookings, and retention.

## What this repo is for
Use this repo to manage:
- brand strategy
- content planning
- booking support
- lead conversion messaging
- competitor tracking
- scheduler operations
- retention strategy

## Recommended weekly workflow
### Monday
- review bookings
- choose weekly hero offer
- review content plan

### Midweek
- post conversion content
- check DMs and follow-ups
- push urgency if openings appear

### Friday
- review what worked
- note strongest hooks
- prepare next week
